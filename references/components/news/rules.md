# News 资讯

> 一级分类【业务组件】下的第一个组件（资讯组件）。2026-10-26 对 Figma 页面 `5153:14`（资讯News🆕）完成真审计；结构化真值见 `schema.json`、`mapping.json` 与 `references/tokens/components/news.tokens.json`，差异与默认处理见 `audit.md`。

#### 用途

- 用于新闻、资讯、公告、研报/报告等**内容条目**的列表或卡片展示，帮助用户快速扫描标题、摘要和来源信息并进入详情。
- 不用于结构化数据比对（用 Table）、指标展示（用 Metric）或带操作按钮的任务列表；条目内不放按钮、开关等二级操作。
- 研报、公告等没有封面图的条目，使用**无图片占位封面**，保持与有图条目相同的列表结构（见 NEWS-006）。

#### 组成与类型

- `News_List`（组件集，state=Default/hover）：`封面 thumbnail + 内容列（Title + 摘要 + Meta）`，是资讯列表的标准行。
- `News_item/Title`：标题文本 + 可选前置标签（leftTag）+ 可选后置标签（rightTag）。
- `News_item`（组件集，type=image / placeholder）：母版 180×120 封面。`image` 为有图封面，`placeholder` 为**无图片占位封面**（浅蓝渐变 + 白色半透明圆形的固定插图）；两态都可按 `Cornertag` 显示左上角 `Tag_corner`。
- `News_item/thumbnail_large`：310×207 图片大卡，底部渐变蒙层叠白字标题 + 作者 + 日期，用于头条、焦点资讯或宫格推荐位。
- `News_item/author`、`news_time`、`news_view`：16px 图标 + 12/18 文本的元信息原子件。

#### 尺寸与间距

- 列表项：内边距 12，封面与内容列间距 20，hover 背景圆角 12（Radius-LG）。宽度 Fill 父容器，推荐最小 480px。
- 列表：**列表项之间上下间距为 0**，视觉间隔由列表项自身 12px 内边距形成，不再额外加 margin/gap。需要更强分隔时使用分割线列表 `gj-news-list-divided`：分割线复用 Divider 规格（`Border/default`、1px），**分割线上下各留 4px 空白**（分割线列表的项间距 = 4 + 1 + 4），左右缩进 12 与列表项内容对齐（Divider inset=content），最后一项下方不画线；悬停或聚焦项自身及其上方一条分割线隐藏，避免与浅蓝背景叠压。同一列表内不混用两种形式。
- **同一列表内摘要统一显示或统一隐藏**，不出现有摘要与无摘要条目混排；作者、日期、阅读量的显示口径同样按整列统一（单条缺数据时隐藏该项）。
- 封面：母版 180×120、圆角 8，图片 `object-fit:cover`。**在列表项内，封面高度等于右侧内容列高度，宽度按 180:120（3:2）等比缩放**（Figma STRETCH + 固定宽高比，NEWS-001）：有摘要时约 177×118；无摘要时约 93×62；无 Meta 时同理按实际内容缩小。摘要区固定占两行高度（44），一行摘要不会让封面变矮。角标为 Tag_corner black/medium/top_left：高 22、横向内边距 8、左上与右下 8px 圆角，背景 `Background/MK_45`，文字 12/18 Semibold 白色。
- 内容列：Title、摘要、Meta 之间纵向间距 12；Title 内部间距 8；Meta 顶部额外 8px 内边距，各项之间间距 16，图标与文字间距 4。
- 大卡：Figma 母版 310×207、圆角 12；运行时宽度由父级网格等分，保持 310:207 高宽比，推荐 3–4 列、gap 16（NEWS-004）。蒙层内边距 上 12 / 左右 16 / 下 16，标题与 Meta 间距 8。

#### 文字与颜色

- 标题：中文/S4-CN-S 16/24 Semibold，`Text/Primary`，**单行省略**；前后标签不压缩。
- 摘要：中文/S8-CN-R 14/22，`Text/Secondary`，**固定两行高度**，超出省略号。摘要为可选（Figma 属性「摘要」）；关闭后封面随内容等比缩小。
- Meta：中文/S9-CN-R 12/18，`Text/Tertiary`（比摘要弱一级）；图标 16px 使用组件库 `icf_user_user`（作者）、`icf_system_calendar`（日期）、`icf_system_eye`（阅读量），颜色跟随文字。
- 大卡：标题 16/24 Semibold、Meta 12/18，全部 `Text/reversal`；蒙层 `linear-gradient(180deg, Background/MK_3, Background/MK_80)`，保证任何封面上白字可读。不得改用纯色遮罩或删掉蒙层。

#### 标签使用

- 前置标签：Tag Light + Blue + Regular（22px），表达**内容分类**，如“宏观”“策略”“公告”。分类标签可按分类体系换色（同 Tag 规则：分类标签不承载状态语义），但同一列表内同一分类颜色保持一致。
- 后置标签：Tag Filled + Red + Small + Pill（18px），表达**热度/时效强调**，如“HOT”“NEW”“置顶”。一条资讯最多一个后置强调标签，不在每一条上都挂。
- 封面角标：Tag_corner，用于来源或栏目（如“资讯标签”“晨会纪要”），文字不超过 6 个字，不遮挡封面主体。无摘要的紧凑列表封面较小（约 93px 宽），角标文字建议不超过 4 个字。
- **前置标签（LeftTag）与封面角标（Cornertag）默认互斥**：两者都用于标识条目归属，同时出现会重复表达、分散视线，一条资讯只选其一，且同一列表内用法一致。仅当业务需求明确两者承载不同标签类型（例如前置标签表示内容分类、角标表示来源栏目）时才允许同时显示，并在需求中写明两类标签的含义。
- 标签文案沿用 Tag 规则：2–6 个字为宜，不换行。

#### 元信息

- 作者、日期、阅读量三项按 `author / date / view` 布尔独立显隐；后端没有该字段时直接隐藏该项，不显示“--”或空占位。
- 列表日期格式 `YYYY-MM-DD 星期X`；大卡日期 `YYYY-MM-DD`，不带图标、不带星期。当天资讯也使用完整日期，不混用“刚刚 / 3 小时前”与绝对日期。
- 阅读量显示整数；≥10000 建议显示为 `x.x万`，同一列表口径一致。

#### 列表统计栏（筛选结果条）

- Figma `列表统计栏`（`5377:383`）。**只在用户进行了筛选或搜索后显示**，用于告知当前结果数量与排序方式；默认浏览（未筛选、未搜索）时不显示，不能作为列表的常驻标题栏。
- 结构：左侧「已为您筛选 + 数量 + 单位」，右侧当前排序方式（如“按发布时间排序”），两端对齐。左侧三段间距 4；说明文字 中文/S9-CN-R 12/18 `Text/Secondary`，数量 中文/S5-CN-S 14/22 Semibold `Text/Primary`；排序文字 12/18 `Text/Secondary`。数量使用 UI 字体，不使用 GJType。
- 单位跟随内容类型：篇资讯 / 篇研报 / 条公告等，与列表内容一致；数量超过 9999 显示 `9999+`，其余显示精确整数（可带千分位）。
- 位置：放在筛选区或搜索框之下、资讯列表之上；左右缩进 12 与列表项内容对齐，与列表间距 4（文字到首条内容约 16）。
- 结果为 0 时保留统计栏显示 `0`，下方用 Empty 说明无结果；加载中隐藏数量或用 Skeleton 占位，不显示上一次的旧数量。
- 右侧排序文字是当前排序的说明，不是可点击控件；需要切换排序时改用 Dropdown 或 Text Button，并保持同一位置。
- 共享基座：`gj-news-stats` / `gj-news-stats-summary` / `gj-news-stats-count` / `gj-news-stats-sort`。

#### 交互与状态

- 图片失败兜底加载共享 `assets/scripts/gj-news.js`：仅隐藏失败的封面图片，让基座已有占位背景露出；图片恢复后重新显示。运行时同时处理初始图片和动态插入图片，不拦截链接导航；不得在每张卡上复制 `onerror`。

- 整个列表项是一个可点击热区（推荐 `<a class="gj-news-item">`），hover 仅切换 `Background/Hover` 背景；Figma 无 pressed/selected/disabled 态，不自行增加（NEWS-003）。
- 键盘焦点使用 `:focus-visible` 2px `Border/focused` 焦点环，鼠标点击不显示焦点环。
- 大卡为整卡链接，Figma 无 hover 态，不添加放大、阴影或位移动效。
- 已读/未读、收藏等状态 Figma 未定义，业务需要时提出补充，不在本组件内临时用颜色区分。

#### 组合与边界

- 资讯列表一般放在 L1 白色卡片内，上方可配 Tabs 做栏目切换，底部使用 Pagination 或“查看更多”Text Button；空数据用 Empty，加载中用 Skeleton，不与正常列表同时出现。
- 头条区可用 1 张大卡 + 右侧 News_List，或 3–4 张大卡等分一行；大卡与列表混排时两者顶部对齐。
- 无封面数据时不放 `<img>`，`gj-news-thumb` 自动显示占位封面（资源 `assets/images/news/thumbnail-placeholder.png`，来自 Figma `5377:359` 原图）；图片加载失败同样露出占位封面。不得用纯色块、默认图标或其它图片替代占位封面，也不得因无图而隐藏封面位。大卡无图时复用同一占位图。
- 共享基座：列表 `gj-news-list`（分割线列表加 `gj-news-list-divided`）/ `gj-news-item` / `gj-news-thumb` / `gj-news-content` / `gj-news-title` / `gj-news-title-text` / `gj-news-summary` / `gj-news-meta` / `gj-news-meta-item` / `gj-news-meta-icon`；大卡 `gj-news-card` / `gj-news-card-img` / `gj-news-card-overlay` / `gj-news-card-title` / `gj-news-card-meta`。标签复用 `gj-tag` 与 `gj-tag-corner`，不得在页面里重画。

## 资讯详情页模板（页面间距规则，不是组件）

> 来源 Figma `5377:980`（模板），2026-10-26 只读核实。仅沉淀间距与边距规则，不建组件基座、不进规范站预览。生成资讯 / 研报详情页时按本节组织结构；具体控件（Tag、Divider、Icon、File Icon）仍引用各自组件规范。

#### 整体结构

- 页面主体由两张 **L1 白色卡片**纵向排列：标题卡 + 正文卡，卡片间距 **16**（L1 gap）。卡片宽度 Fill 内容区，外侧页面边距按全局页面布局规则，不在详情页内另设。
- 两张卡片均为 `Background/Container`、圆角 **12**、内边距 **20**（四边）。Figma 中正文卡外层「详情主栏」与内层「报告标题卡片」是同底色、同圆角的两层嵌套，实现时合并为一张卡，不叠两层容器。

#### 标题卡

- 标题与元信息行纵向间距 **12**。
- 标题：中文/S2-CN-S 20/30 Semibold，`Text/Primary`，宽度 Fill，可换行，不截断。
- 元信息行：横向，元素间距 **16**，垂直居中；依次为类型标签（Tag Light / Blue / Regular，可带 12px 图标）与发布日期（中文/S9-CN-R 12/18，`Text/Tertiary`）。

#### 正文卡

- 正文卡内各区块（PDF 全文入口 → 正文内容 → 免责声明）纵向间距 **20**。
- **PDF 全文入口**：整块可点击，`Background/Background` 灰底，内边距 **16**，圆角 **8**（Radius-MD，L2 分区），左右两端对齐、垂直居中，与右侧箭头间距 12。左侧文件图标 `fileicon/pdf` 32×36，与文字列间距 **12**；文字列内上下间距 **2**：文件名 中文/S5-CN-S 14/22 `Text/Primary`（单行，超长省略），提示「点击查看完整研报 PDF」中文/S9-CN-R 12/18 `Text/Tertiary`。右侧 `icf_Arrow_right` 16px。
- **正文内容**：各段落组（如「报告摘要」「点评」）之间间距 **16**；组内小标题与正文、正文段落之间间距均为 **8**。小标题 中文/S4-CN-S 16/24 `Text/Primary`；正文 中文/S8-CN-R 14/22 `Text/Primary`，按段落拆分，不用空行或 `<br>` 撑间距。
- **免责声明（收起态）**：区块上下内边距 **16**、左右 0，内部纵向间距 **16**。顶部为「Divider — 查看免责声明 + 向下箭头 — Divider」的居中标题行，元素间距 **4**，两侧 Divider 平分剩余宽度；文字 中文/S6-CN-S 12/18 `Text/Tertiary`，箭头 `icf_Arrow_down` 16px。正文 中文/S9-CN-R 12/18 `Text/Tertiary`。「投资评级说明」组内间距 **8**：标题 中文/S6-CN-S 12/18 `Text/Secondary`，说明 S9 `Text/Tertiary`。
- 由于区块间距 20 叠加免责声明上内边距 16，正文末段到免责声明分隔线的视觉距离约 36，属模板有意加大的弱化分隔，不要压缩成 20。
