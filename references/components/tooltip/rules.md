# Tooltip 文字提示

> 2026-09-08 基于 Figma 节点 `3582:1816`（toolip，dark）、`3630:3385`（toolip_fill，light）与文档页 `3623:2` 提取；同日经设计侧确认关闭全部 5 项待确认（见 `references/audit-tracker.md` TLT-001~005），04 Content / 05 Accessibility / 06 Boundary & DoDont 三个章节的内容已在下方补齐。同日设计侧进一步指示将 position 精简为仅 top_center（TLT-007，已关闭）；Figma 源文件抽取时仍含 8 个 position 变体，由设计侧后续手动同步简化，本次仅更新 Skill 契约层与预览页。

## 用途

- Tooltip 用于解释图标、字段、缩写或被截断内容，信息轻量、只读，不承载操作。

## 何时使用 / 不适用

- 适用：解释仅图标按钮的含义、专业术语或缩写、字段补充说明、被截断内容的完整文本。
- 不适用：必须被用户看到的信息、错误与风险提醒、包含按钮或链接的交互内容、需要多段说明的帮助内容——这些场景改用 Modal、Notification 或 Popover。
- 点击触发且需要持续停留的内容使用 Popover，不使用 Tooltip。

## 属性枚举

- `position`：仅支持 `top_center`（设计侧确认精简，2026-09-08；此前的 8 个方向已停用，Figma 源文件抽取时仍含 8 个变体，由设计侧后续手动同步简化）。
- `style`：`dark`（默认）/ `light`。dark 为通用默认场景使用；light 一般不使用（设计侧确认，2026-09-08）。Figma 源文件中这两种风格保留为两个独立组件集（`toolip` / `toolip_fill`），暂不合并；本 Skill 与规范页在契约层用 `style` 属性把两者抽象为同一组件的两种取值，两种表达并存、互不替代。
- `polygon`：是否显示指向触发元素的箭头，默认 `true`。

## 尺寸与视觉

- 圆角 8px，内边距 16px——设计侧确认为固定值（硬编码），不绑定圆角/间距变量（2026-09-08）。
- 文字使用 `中文/S8-CN-R`（PingFang SC Regular，14px / 行高 22），内容区最大宽度 206px，超出换行。
- `dark` 风格：背景 `Background/MK_80`（`#000000cc`），文字使用 `Text/reversal` 语义变量（白色），无阴影。
- `light` 风格：背景 `Background/Container`（白色），文字 `Text/Primary`（`#101828`），固定宽度 240px，使用 `shadow-center` 阴影效果（`Background/MK_10`，blur 15）。
- 箭头为 16×10px 三角形，固定朝下指向触发元素（仅支持 `top_center`，不再需要旋转）；`dark`/`light` 各自使用独立的箭头资源，颜色跟随所在风格的背景色（设计侧确认，2026-09-08）。

## 触发与关闭

- 鼠标 Hover 延迟 300–500ms 出现；键盘 Focus 时立即出现，避免操作过程产生闪烁。
- 鼠标离开触发元素与 Tooltip 后延迟 100–200ms 关闭；按 Esc、滚动页面、窗口变化或触发元素消失时关闭。
- 同一区域一次只展示一个 Tooltip。

## 位置与避让

- 固定使用 `top_center`，与触发元素保持 8px 间距；箭头必须精确指向触发元素（通常是图标）的视觉中心，不能偏移。
- 不再支持其他方向或自动翻转避让（设计侧确认精简，2026-09-08）；若后续空间不足导致遮挡，由设计侧另行评估调整，不在本组件内做自动降级。

## 内容与文案

- 一次只解释一个概念；推荐 12–30 个中文字符，建议不超过 3 行，最多 4 行。超过时改用单独页面或帮助内容。
- 短语不强制句号，完整句使用正常标点；直接说明含义，不使用"提示："“这里是”等冗余前缀。
- 不放置按钮、链接、输入项或实时变化的重要数据；不要重复界面上已经清楚呈现的标签。

## 可访问性

- 触发元素必须可键盘聚焦；使用 `aria-describedby` 关联 Tooltip，浮层使用 `role="tooltip"`。
- 不得把完成任务所必需的信息只放在 Tooltip 中；文字与背景对比度至少 4.5:1。
- Tooltip 内不包含可聚焦控件；Hover 展示的内容需可悬停，且支持 Esc 关闭。

## 组件边界与推荐 / 避免

- **Tooltip**：Hover / Focus 触发，解释当前元素，无操作。
- **Popover**：Click 触发，可承载较复杂信息和操作，持续停留。
- **Toast**：全局结果反馈，与当前元素无锚定关系，短时自动消失。
- 推荐：解释图标、补全截断文字、保持简短、自动避让。
- 避免：隐藏必填标签、承载按钮、显示错误警告、页面加载后主动弹出、放置长段帮助内容。
- Do not infer placement, arrow, size, delay, states or tokens from Popover or Chart tooltip：图表内部的数据点提示是独立机制，不与本组件共用规则或样式。

## 边界

- Tooltip 始终不可点击、不可获得焦点，也不承载展开、跳转或选择行为；这些行为由触发它的元素或改用 Popover 承担。
