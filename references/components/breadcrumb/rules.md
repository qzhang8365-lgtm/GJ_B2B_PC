# Breadcrumb 面包屑

> 从 `references/design-system-rules.md` 拆分（2026-09-08）。跨组件的颜色/字体/布局/圆角等基础规范见该文件“基础规范”章节。

#### 用途与结构

- Breadcrumb 显示当前页面在系统层级中的位置，并允许返回任意历史上级页面。
- 路径由历史层级、分隔符和当前页面组成。
- 当前页面只说明位置，不重复触发当前页面导航；历史层级可点击返回。
- Breadcrumb 不代替 Sidebar、Navbar 或 Tabs，只补充当前位置与返回路径。

#### 属性与枚举

- `items`：层级数据，数量按产品真实信息架构自定义，最少包含一个上级和当前页面。
- `current`：末级当前页面，必须唯一。
- `icon`：`false / true`；每一级可选显示 16px 图标，与文字间距 4px；图标必须来自图标库，颜色跟随该级文字。
- `collapse`：是否折叠中间层级；这是长路径展示选项，不是业务层级数量限制。
- Figma 的 `Count: 2 / 3 / 4 / 4+` 是常用展示预设；实际实现允许自定义层级数量。

#### 尺寸与 Token

- 组件高度 22px。历史项与当前项文字使用 `中文/S8-CN-R`：14/22、400。
- 历史路径使用 `Text/Tertiary`；Hover 使用 `Text/blue`（Figma 无 Hover 轴，已写入组件 Token）。
- 当前页面使用 `Text/Primary`，Hover 不改色。
- 图标尺寸 16px，图文间距 4px（`Interval/space2`），颜色跟随对应层级文字。
- 分隔符为 `/`，左右各 8px，颜色 `Background/MK_30`。Figma 分隔符仍绑旧 `Body/regular`；实现保持 UI 字体 14/22/400，不引入 Roboto。

#### 层级与折叠

- 层级数量由产品信息架构决定，不设置强制四级上限。
- 路径较长时建议折叠中间层级，保留首层、靠近当前页的上级和当前页面。
- “4+ 折叠”只是推荐展示方式，不代表超过四级不允许存在。
- 折叠项使用省略入口，不把隐藏层级直接删除；用户仍应能访问被折叠路径。
- 点击省略项时使用 Dropdown 展示被折叠层级，不在原位置突然展开整条路径。

#### 内容边界

- 各级名称应与对应页面标题或导航节点一致，不自行使用缩写造成名称不一致。
- 名称保持简短、稳定和单行；当前页面名称不能仅显示无意义的“详情”而缺失对象语义。
- 当前页面不可点击，历史项必须具有 Hover 和 Focus 反馈。
- 不同时混用多种分隔符或在同一条路径中改变图标风格。
- 面包屑宽度不足时，先折叠中间层级，始终保证第一层和最后一层可见，不使用横向滚动。
- 单个层级名称建议最多 8–10 个字；超过时单行省略，并在 Hover 时通过 Tooltip 显示完整名称。
