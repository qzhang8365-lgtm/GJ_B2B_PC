# Pagination 分页

> 从 `references/design-system-rules.md` 拆分（2026-09-08）。跨组件的颜色/字体/布局/圆角等基础规范见该文件“基础规范”章节。

#### 用途与类型

- Pagination 用于将大量连续数据拆分为多个页面，适用于表格、列表和检索结果等数据集合。
- `type`：`Default / Mini / Full`。
- Default 是常规分页，适用于标准桌面内容区。
- Mini 是紧凑分页，只在空间受限且仍需保留页码导航时使用，不以缩小字号替代正常布局调整。
- Full 用于需要同时表达数据总数、页码和快速跳转的大数据集合。
- 内容能在一页完整展示时默认不显示分页器，避免出现只有页码 1 的无意义控件；需要维持固定布局的特殊页面可由设计稿另行定义。

#### 子项属性与枚举

- 数字项 `Pagination_item/number`：
  - `Size`：`Default / mini`。
  - `state`：`default / hover / selected / disabled`。
- 箭头项 `Pagination_item/arrow`：
  - `Size`：`Default / small`（实现归一为 mini）。
  - `direction`：`previous / Next`。
  - `State`：`Default / hover / disabled`。
  - `double`：`false / true`；双箭头表示按页段快速后退或前进，不表示直接回到首页或末页。Figma 三套组合默认不含双箭头，由产品按需组装。
- 跳转项 `Pagination_item/jump_to` 是独立件：Figma 文案为 `Go to`，产品可用「跳至」；由标签和页码输入框组成，按 Enter 或明确提交动作执行跳转。
- `type`：Figma `default / mini / type4`；`type4` 即 Full。
- 当前页在同一分页器内必须唯一；页码、上一页、下一页和跳转操作不得产生多个 Selected 项。

#### 尺寸与 Token

- Default 数字项和箭头项为 32×32px；Mini/Small 为 24×24px。箭头 Default 内边距 6、图标 20；Mini 图标 16。
- 相邻页码默认间距 4px；Full 的总数与页码组外间距 8px。圆角字面 6px。
- 跳转输入框为 48×26px，圆角 4px，`Background/Container` + `Border/default`；标签与输入框间距 8px。
- 默认数字使用 `中文/S8-CN-R`：14/22、400；Selected 使用 `中文/S5-CN-S`：14/22、600。
- 数字默认 `Text/Primary`；Hover 只改 `Text/blue`、无背景；Selected 文字 `Text/blue`、背景 `Background/Selected`；Disabled `Text/disable`。
- 箭头默认/Hover/Disabled 图标均为 `Text/Tertiary`。Hover 背景 `Background/Hover_2`。Disabled 再加 40% 透明，不用 `Text/disable`。
- 省略图标 `icf_system_more` 使用 `Text/disable`。箭头与省略必须引用已上传图标库资源。

#### 页码范围与省略（2026-09-10 设计确认，通用规则补充，关闭 PAG-001）

- 总页数 ≤ 7 时连续展示全部页码；不得为了填满宽度额外制造省略项。
- 总页数 > 7 时按业界通用的「首尾固定 + 当前页左右各留 1 页 + 单侧省略」规则折叠：
  - 首页（第 1 页）与末页（最后一页）始终展示，不会被省略。
  - 当前页左右各保留 1 页作为相邻页码；当前页处于两端附近、相邻页码与首尾重叠时不重复显示。
  - 首页/当前页左侧相邻页码之间如果间隔 ≥ 2 页，用一个省略项折叠该区间；当前页右侧相邻页码/末页之间同理。省略区间只用一个省略符号代表，不展示具体折叠了多少页。
  - 同一侧最多出现一个省略项；页码总数较少、折叠后两侧省略区间几乎相邻时，直接展示具体页码，不为了"好看"强行省略只省了 1 页的区间（间隔为 1 时直接显示该页码，不用省略号替换单个页码）。
  - 示例：总页数 20、当前第 5 页 → `1 2 3 4 5 6 … 20`（左侧无需省略，右侧间隔≥2 用省略）；当前第 10 页 → `1 … 9 10 11 … 20`（两侧都省略）。
- 省略项用于压缩长页码范围，不代表数据缺失；省略号不可点击，也不展开页码菜单，不可聚焦。
- 首页和末页显示的数字已经明确可跳转范围；用户需要前往指定中间页时使用 Full 类型的跳转组件。
- 分页器不得通过横向滚动容纳页码，也不得无限压缩字号和点击区域。

#### 状态与边界

- 第一页必须禁用上一页和向前快退；最后一页必须禁用下一页和向后快进。
- 双箭头默认用于按 5 页或 10 页为单位快退、快进；具体步长由数据规模和产品场景统一设置，同一分页器内前进与后退步长必须一致，且不得在操作过程中变化。
- 快进或快退不足一个完整步长时，停在第一页或最后一页，不产生超出有效页码的状态。
- Disabled 项不可聚焦触发、不可点击，并保持清楚但弱化的可识别状态。
- 切换页码后保留当前筛选条件、排序方式和每页条数，不把用户恢复为未经筛选的初始数据。
- 切页完成后内容区域回到合适的阅读起点，并给予加载中、加载完成或加载失败反馈；分页器本身不得伪造成功状态。
- 数据变化导致当前页超过新总页数时，应回退到仍然存在的最后一页，而不是展示空白的失效页码。
- 无数据时不显示分页器，并由数据容器展示空状态。

#### 快速跳转与校验

- 跳转输入只接受有效整数；空值、非数字、小于 1 或大于总页数均不得执行跳转。
- 非法输入应给出明确反馈，并保留用户修正输入的机会。
- 输入当前页码时不重复请求或制造页面闪动。
- Full 类型是否同时显示每页条数选择器由具体业务决定；如提供，选项应预设且稳定，不允许任意自由输入条数。
- 修改每页条数后必须回到第 1 页，并重新计算总页数，避免保留一个在新页码范围中无对应上下文的旧页码。

#### 内容与组合规则

- 分页器应与其控制的数据容器形成明确归属，通常放在列表或表格底部，不悬浮在无关内容之间。
- 分页器的水平位置由页面内容形态、容器基线和用户操作动线决定，不设置全局固定对齐方式：
  - 右对齐：适用于绝大多数数据表格、列表页和管理后台等操作型场景；用户完成内容操作后视线通常自然落在右下角，可保持操作连贯性。这是 B 端页面最常用的对齐方式。
  - 居中对齐：适用于卡片流、网格卡片、搜索结果、文章列表和内容资讯等以浏览为主的页面。
  - 左对齐：适用于内容区域较窄且页面存在明确左侧对齐基线的情况，使用频率较低。
- 同一列表或表格区域内，分页器应跟随内容容器而不是浏览器视口对齐；同类页面应保持相同的对齐逻辑。
- 总数、每页条数、页码和跳转控件应在同一行保持基线与垂直居中；空间不足时优先精简辅助信息，不压缩核心页码点击区域。
- Default、Mini 和 Full 是不同密度方案，同一数据区域只使用一种，不叠加多个分页器表达同一页码状态。
- 图标、文字和输入框的实际视觉值以 Figma 组件实例为准；业务实例的局部覆盖不自动成为全局分页规范。


#### 使用场景与选型（Figma 使用说明补充，2026-09-10，来源节点 `4806:20549`）

- **要不要用分页器**：用户是否需要"跳转到第 N 页"或"回到刚才那页"？需要就用分页器；如果只是"一直往下刷"，用无限滚动，不用分页器。

- **按场景选型**（Figma 原文，注：Figma 该表第 3 行"用户需调整浏览密度→每页条数选择"的说明文字与第 2 行重复，判断是内容占位错误；第 5 行标了"（待补充）"但实际给出了正确说明，本节按第 5 行取值，不采用第 3 行的重复描述）：

  | 场景特征 | 选型 | 说明 |
  |---|---|---|
  | 数据量大的结构化列表 | 完整分页器（Full） | 提供明确的定位感，适合后台管理、搜索结果等需要精确跳转的场景 |
  | 轻量化内容 | 迷你版分页器（Mini） | 仅保留核心翻页功能，适合卡片或内嵌小组件 |
  | 数据量极大 | 带快速跳转 | 提供输入框，让用户直接输入页码跳转，避免连续点击 |
  | 用户需调整浏览密度 | 每页条数选择 | 允许用户自定义每页显示多少条，常见选项如 10/20/50 |

  「带快速跳转」「每页条数选择」是可叠加的功能开关，不是与 Default/Mini/Full 互斥的第四种 `type`；是否启用由具体业务场景决定，不强制绑定某一 `type`。

- **位置摆放**（Figma 给出的三种具体落位，均可用，按页面类型选择）：

  | 位置 | 说明 |
  |---|---|
  | 列表/表格底部居中 | 最通用，视觉重心平衡 |
  | 列表底部右侧 | 后台系统常见，与"共 N 条"配合 |
  | 表格底部左侧放总数、右侧放分页 | 企业级后台标准布局 |

- **摆放原则**：
  - 紧贴内容区：与列表保持 16–24px 间距，形成归属感。
  - 不要放在筛选区上方：分页是对结果的导航，应位于结果之后。
  - 弹窗/抽屉内使用时：放在弹窗底部，与操作按钮同区，但不要和"确定/取消"混排。

- **宽度适配**：
  - 内容区宽度足够：居中或右对齐，完整展示页码 + 每页条数 + 跳转。
  - 内容区较窄：使用省略号折叠，形如 `1 … 4 5 6 … 20`。
  - 超宽屏：不要拉满整行，分页器本身宽度固定，靠左或居中即可，避免按钮间距被拉大。
