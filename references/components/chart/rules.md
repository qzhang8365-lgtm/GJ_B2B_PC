# Chart 图表

> 从 `references/design-system-rules.md` 拆分（2026-09-08）。跨组件的颜色/字体/布局/圆角等基础规范见该文件“基础规范”章节。

#### 公共基础

- 先按数据关系选图：趋势用折线/曲线，离散比较用柱状，构成用饼/环/百分比，维度比较用雷达，单目标达成用仪表或进度，关键词权重用词云。
- 数据系列按 `Chart/CH01–CH10` 连续取色；同一页面、同一指标在不同图中保持颜色映射稳定，不使用临时色。
- Y 轴标签右对齐、12/18；非零刻度使用虚线，0 刻度与 X 轴共用实线基线。X 轴刻度支持 Time/Month/Days/Quarterly，单位必须明确。
- Legend 类型支持 Line/Block/Dot/Dot+Line；默认横向、项间距 16px，饼图右侧或空间不足可纵向、间距 8px。
- Tooltip 单指标显示日期、数值、单位；多指标显示标识、名称和值。Tooltip 数值使用当前 UI 字体；涨跌平引用对应 Feedback Token。
- Data Indicator 在 Hover 临时出现、Selected 持续；多系列显示同一刻度的全部节点，不默认长期铺满数据圆点。
- 图表必须提供无数据、加载、错误和极端值处理；不能只用颜色区分系列，Tooltip/Legend/标签需保留可识别名称。

#### 整体比例与轴线搭配（2026-09-10 新增，local-contract 规则，非 Figma 逐值核对）

> 不参考 Figma 复合组件（轴线+图表）的内部约束——业务场景差异大，需要灵活调整；以下是按数据可视化通用原则、结合本设计系统既有 Token（Interval 间距级、字体、圆角）新拟定的比例规则，用来把「轴线」和「图表主体」的搭配补齐，弥补此前只描述了柱体/图例/圆角等局部数值、缺少整体比例公式的缺口。

- **Y 轴预留宽度**：按当前刻度文案实际渲染宽度动态测量（12/18 字体），不使用固定像素；测量宽度 + `Interval/space3`（8px）作为标签到绘图区/轴线的间距，得到 Y 轴预留总宽度。预留宽度下限 32px（应对极短标签如个位数、百分比）。
- **X 轴预留高度**：默认单行标签，高度 = 字体行高 18px + `Interval/space2`（4px，轴线到标签的间距）；标签过长不换行，超出可用宽度时省略并靠 Tooltip 补全，不得因为换行让 X 轴带高度失控。
- **绘图区内边距**：顶部默认 `Interval/space3`（8px），若开启 Data Label（如柱状图顶部数值）需再加一行标签高度（14/22，约 22px）作为顶部余量，避免数值被裁切；右侧默认 `Interval/space3`（8px），保证最后一个数据点/端点圆点（>=8px）不贴边。
- **标题区到绘图区间距**：`Interval/space5`（16px）。
- **图例到绘图区间距**：图例在下方时取 `Interval/space4`（12px）；图例在右侧（饼/环常见布局）时与绘图区保持 `Interval/space6`（20px）横向间距。
- **网格线**：默认 3 条非零虚线参考线 + 1 条零刻度实线基线，共 4 条水平线，按数值取整到「整洁数字」（如 0/1000/2000）分档，不按像素等分文本刻度；网格线数量可根据数值范围调整，但不建议超过 5 条，避免绘图区视觉噪音过高。
- **柱状图类目间距与柱宽算法**（把此前"根据分类带宽和组内系列数自动计算"补成具体公式）：
  1. 类目带宽 = (绘图区宽度 − (类目数 − 1) × 类目间距) / 类目数；类目间距默认 `Interval/space5`（16px），当类目数量增多、可用宽度不足时可压缩到下限 `Interval/space3`（8px）。
  2. 单类目内：若为分组柱，柱宽 = (类目带宽 − (系列数 − 1) × 4px) / 系列数（4px 为既有的并列柱组内间距），结果限制在 12–40px。
  3. 计算结果超过 40px（类目少、画布宽）时，柱宽封顶 40px，多余空间平均分配为更宽的类目间距，柱体/柱组在类目带宽内居中，不放大柱宽突破上限。
  4. 类目间距已压缩到 8px 下限、柱宽仍低于 12px 时，不再压缩：应减少可见类目、改横向柱状图，或启用横向滚动（沿用既有规则），不得把柱宽压到 12px 以下。
- **默认高度预设**：折线/曲线/柱状/百分比等矩形绘图区图表，卡片高度（含轴线带）建议从三档预设中选择——紧凑 200px（列表内嵌趋势图）、标准 300px（与既有规范页演示一致）、大尺寸 400px（详情分析视图）；宽度默认跟随容器流式响应，不固定宽高比。绘图区最小可用高度（不含标题/图例/轴线带）不低于 120px，低于该值改用 Sparkline 或数值卡片。
- **圆形类图表**（饼/环/仪表/环状进度）：固定 1:1 宽高比，直径默认 200px，下限 120px，上限跟随布局容器；不套用矩形图表的高度预设。
- **响应式收缩顺序**：容器变窄时，优先级从高到低依次为——图例从右侧收纳到下方 → 压缩类目间距至 8px 下限 → 减少可见 X 轴刻度密度（跳标签，不旋转文字）→ 柱状图触发横向滚动或切换横向布局。不得为了保留全部刻度文字而旋转或换行标签。

#### 折线与曲线

- 折线表达阶段变化和转折；平滑曲线用于强调连续趋势，不用于掩盖真实突变。支持单/多系列，默认可使用同色低透明 Fill。
- 单系列使用 CH01；多系列按 CH 顺序映射。默认不持续展示节点，Hover/Selected 时出现 Indicator 与 Tooltip。
- 多系列 Fill 必须足够透明，避免重叠区域遮挡；数据点过密时降低标签密度，不任意平滑或删除数据。

#### 柱状图

- 支持垂直/横向、Single/Grouped/Stacked、正负值；柱厚自动限制在 12–40px，并列柱组内间距 4px。
- Single 与正负柱圆角 4px；Grouped/Stacked 圆角 2px，Stacked 分段间距 2px。正负值共用清晰零基线并向相反方向生长。
- Data Label 默认可开，字号不得小于 14px；Stacked 只在整柱外显示总值。空间到 12px 下限后不再压缩，应减少类别、扩大画布或滚动。

#### 饼图、环形图与百分比

- 饼/环支持 2–10 个指标，按 CH01–CH10 分配；指标过多或比例过近难以比较时改用柱状图。
- 饼图比例标签字号至少 14px，扇区不足时隐藏但图例保留；Hover 只突出当前扇区，不改变颜色映射。
- 环形分段间留清晰间隔，端角圆角不大于 4px；中心可显示总量，不能因 Hover 改变中心结构。
- 横向百分比各段间距 2px、圆角 4px；所有部分必须构成同一整体，比例总和与数据逻辑一致。

#### 雷达、仪表、进度与词云

- Radar 支持 3–10 个维度、1–3 组；维度标签始终显示，端点显示，Fill 默认开启但重叠严重可关闭。9–10 维应使用简短标签并适当扩大绘图区，标签不得互相遮挡；各系列必须使用相同量纲或归一化尺度。
- Gauge 只保留 Half Circle 与 Three-quarter Circle；中心显示指标名和完成率，核心值 GJType 36/44、700；进度 CH01，轨道 `Background/Secondary`。
- Progress 圆头轨道高 8px，强调条高 16px；列表比较独立进度，单项条可用多个分段表达构成。值需限定有效范围，超过目标时应明确业务含义。
- Progress Ring 用完整圆环表示单项或多个并列任务，不与 Pie 混用表达构成；中心数值与外圈颜色映射保持一致。
- Word Cloud 通过气泡面积、字号和背景强度表达权重，文字保持水平，不随机旋转；必须保留可读性，不能用于精确比较。
