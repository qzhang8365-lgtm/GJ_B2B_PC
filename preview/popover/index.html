居中弹出框 Popover

用于居中呈现短结果或简单确认。组件无指向箭头，内容固定为语义图形、标题、说明和操作区；不把它当作锚定气泡，也不用于复杂表单任务。

组件结构

四段结构垂直居中排列。语义图形是可配置内容插槽，不是 Status 变体轴；操作区只允许一或两个 Button Large。

任务创建成功

任务已进入处理队列，可前往任务中心查看进度。

Container

宽 360px · R16 · shadow-center

上 40px、左右 24px、下 24px；内容栈间距 20px。

Graphic Slot

48×48px · 填充图标

图形必须表达结果或权限语义，使用已登记的 iconfont 资源。

Copy

标题 20/30·600 · 说明 14/22

文案居中、间距 16px，文字区左右再内缩 20px。

Actions

Button Large · 最多两个

单按钮铺满；双按钮等宽，Tertiary 取消在左、唯一 Primary 在右。

操作形式

组件集只有 button=1 与 button=2 两个真实变体；不存在无按钮变体，也不从图标推断 Status 属性。

交互演示

验证两种操作区结构和文案自适应。画板未规定遮罩、视口定位或自动关闭，演示只响应组件内部操作，不扩写生命周期。

属性控制

button 是唯一组件变体轴；标题、说明与图形属于内容配置。

结构与规格

组件尺寸保持固定，响应式断点只改变规范页网格列数，不缩放 Popover、图标或按钮。

反馈层级与选用规则

按信息是否阻断、是否需要操作和内容复杂度选择组件，避免把所有反馈都升级为居中弹出框。

Toast

短消息 · 无操作 · 自动消失

用于保存、复制等即时结果，不要求用户确认。

Notification

非阻断 · 持续显示 · 单操作

用于较完整信息，不中断用户当前任务。

Popover

居中短结果 · 简单确认

最多两个操作，不承载表单、列表或多步骤任务。

Modal

阻断任务 · 复杂决策或录入

需要填写、选择、校验或复杂说明时使用。

短而明确

一个结果或一个问题

标题直接说明结论，正文只补充影响或下一步。

图形有语义

不是装饰插画

结果、权限等场景选用对应填充图标与语义色。

操作收敛

一个主操作，最多一个取消

不增加第三按钮，也不把文字链接塞入操作区。

保持组件边界

不含复杂业务组件

表单、列表、级联选择和多步骤内容应升级为 Modal。
