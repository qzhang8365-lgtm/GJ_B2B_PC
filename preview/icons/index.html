图标 Icon

统一管理全部图标资源，命名规范为 icf_分类_名称，含 fill / line 两种风格。点击图标卡片可查看大图并复制 / 下载资产，搜索支持名称、分类与英文关键词。

图标规则

资产类型与调用方式
General Icon

24×24px 默认画布，2px 描边轮廓化；页面用 gj-icon 通过 --gj-icon 引用资源，颜色继承周围文字。

Effect Icon

渐变、多色和复杂效果保留为独立 SVG，不允许业务侧覆盖内部颜色。

Motion Icon

动效图标采用 Lottie JSON 动画（bodymovin 格式，60fps）；并提供静态 SVG 降级方案。
