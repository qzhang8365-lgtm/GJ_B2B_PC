按钮 Button

用于触发即时操作、提交任务或推进流程。层级表达操作权重，尺寸取决于所在容器；轻量文字触发应使用 Text Button。

操作层级

同一操作区域保留一个最明确的主操作，其余按钮依次降低视觉权重。

Primary / Secondary / Tertiary
Text Button / Ghost

尺寸与图标

默认使用 Medium；同一操作组保持相同尺寸。图标尺寸随按钮档位同步变化。

状态

组件状态包含 default、hover、pressed、disabled；Loading 与短暂 Completed 为运行时状态。

属性控制

选用规则

优先按操作权重和容器层级判断，不按业务名称机械选择。

主题推荐做法边界与避免
用途触发即时操作、提交任务或进入下一流程。不要用 Button 表达导航路径、选项或静态状态。
层级主操作用 Primary；次操作用 Secondary；弱操作用 Tertiary、Text Button 或 Ghost。同一区块尽量只保留一个 Primary，并排时避免同权重。
尺寸按容器层级选 Large 40 / Medium 32 / Small 24；与输入框并排时高度一致。同一操作组不得混用尺寸，不按业务场景名称决定尺寸。
Icon-only仅用于含义明确的图标，并提供可访问名称；工具栏操作使用 gj-btn-icon-only。语义不清时改用图标加文字；Text Button 不提供 icon-only。
反馈状态Loading 使用动态 icon 与场景化文字；短暂 Completed 可按流程需要启用。Completed 是可选反馈，不应成为所有按钮的固定流程。
文案使用清晰的动词或“动词＋对象”，让操作结果可预期。避免过长、含糊或同时表达多个动作。
