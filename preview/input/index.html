输入框 Input

用于接收和编辑单行或多行文本，可结合标签、提示、错误反馈、字数限制及图标，帮助用户清晰完成数据录入。

基础类型

Outlined 适合白色和常规容器；Filled 通过背景区分输入区域。同一业务区域只使用一种视觉风格。

Outlined边框型
Filled填充型

尺寸与状态

Small、Medium、Large 分别对应 24、32、40px；同一表单层级的输入与相邻控件必须使用同一尺寸。

扩展输入

选用规则

字段说明、格式帮助和错误反馈应降低输入成本，不让用户依赖猜测完成表单。

主题推荐做法避免
字段标签使用直白、稳定且符合业务系统的名称；标签默认保留可见。只用 placeholder 说明字段含义。
上下文帮助提供必要的默认值、格式示例与简短帮助文字。让用户在空白输入框中猜测格式。
标签布局同一表单统一左侧或上方布局；长文本、窄容器优先上置。同一层级混用多种标签对齐方式。
错误反馈错误信息紧邻字段，并明确说明如何修正。只显示“Error”或只依赖颜色。
数据提交必要时校验输入并保留用户已填内容。校验失败后清空整张表单。
