整栏选用规则

Usage rules
主题推荐做法边界与避免
栏宽展开 200px，收起 56px，全量采用母版尺寸。不按视口改用标注表中的 208 / 240 / 288 或 64 / 80。
三套表面只切换容器表面与行 mode，结构保持一致。不要为 blue 单独编写布局。
层级饰条1px 饰条只出现在已展开的一级下方；浅色用 MK_10，深色用 BT_DB20。不要与 Border/default 混用。
Hover在默认外观上叠加 Background/Hover。不另造 Hover 色，也不改变字重。

导航行选用规则

sidebar_item
主题推荐做法边界与避免
Active / Selected祖先 Active 只加粗并展开箭头；当前页 Selected 才显示选中底。不得把展开路径全部标成当前页。
图标颜色一级图标跟随文案；dark 模式使用 reversal。MK_20 仅用于 light 默认箭头，不套用到主图标。
blue 容器组合 dark 模式的 sidebar_item。Background 是容器表面，不是 item 属性轴。
Disabled仅在入口不可用且仍需展示信息架构时使用。禁用项不得触发展开或选择。
