01 · SYSTEM OVERVIEW

设计系统包含什么

人工预览站与 AI 可读资产分层存储；页面展示帮助理解，结构化 JSON、规则与校验脚本负责生成时的准确性。

01

基础规范

颜色、字体、布局、圆角与效果 Token，作为所有组件和页面的共同底座。

 02

组件规范

组件 schema、映射、审计、状态 Token 与交互预览，生成前按名称查询。

 03

页面模式

查询列表、表单填写、对象详情、工作台和分步任务五种常用 B 端结构。

 04

资源与门禁

统一图标、字体、构建脚本、覆盖状态和生成后验证，避免凭经验猜测。

HOW TO USE

接入方式

01

下载并解压发布包，保持目录结构不变。

02

把完整目录放入 AI 工具或工作区可读取的位置；入口文件为 SKILL.md。

03

描述要生成或检查的 B 端页面，Skill 会先查询组件契约与 Token，再组合页面。

04

交付前运行 Token、覆盖状态和页面验证脚本，确认没有原生 CSS 替代已有组件。
