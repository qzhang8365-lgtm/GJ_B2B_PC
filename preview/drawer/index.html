抽屉 Drawer

从页面右侧进入的支线任务容器，用于在保留当前上下文的同时查看关联详情、筛选或编辑表单。Header 与 Footer 固定，超长内容只在 Content 内滚动。

组件结构

Drawer 由蒙层、面板、固定标题栏、独立滚动内容区和可选操作区组成；关闭入口始终位于标题栏右侧。

Header

高 64px · 水平 20px

标题 16/24、600；底部使用 Border/Default。

Content

padding 20px · 独立滚动

内容增长时不推动 Header 与 Footer。

客户资料核验
业务内容区域

组合详情、筛选或标准表单组件；内容超长时仅此区域滚动。

Close

图标 24px · 可键盘聚焦

固定在 Header 右侧，保留 Hover 与 Focus Ring。

Footer

padding 20px · gap 8px

可隐藏；Button Large 右对齐，最多一个 Primary。

交互演示

验证右侧进出、尺寸切换、只读 Footer 隐藏、蒙层关闭开关、未保存保护、焦点进入与返回。

当前业务页面

Drawer 打开后保留当前页面上下文，由蒙层降低背景干扰。关闭后焦点返回下方触发按钮。

编辑任务信息

放弃未保存的更改？

关闭抽屉后，本次修改将不会保留。

属性控制

默认 Medium、显示 Footer、禁止点击蒙层关闭；dirty=true 时所有关闭入口都先确认。

尺寸与结构

Medium 是桌面端默认；始终选择能容纳内容的最小档位，不通过加宽制造留白。

尺寸宽度推荐内容边界
Small400px快速查看、单组筛选、少量字段轻量任务优先，不堆叠高密度分区
Medium600px常规详情、多字段表单桌面端默认，满足大多数支线任务
Large800px高密度信息、分区表单、复杂操作仅在内容确实需要横向空间时使用

组件边界与行为规则

预览页只展示选型所需的关键差异和高风险行为；完整约束仍以组件契约与规则文件为准。

承载方式任务关系适用场景不适用
Drawer 当前保留上下文的支线任务关联详情、筛选与编辑多步骤或需要完整工作区的流程
Modal集中决策、中心阻断短确认或必须立即处理的任务强调页面侧向关系的复杂内容
Page独立流程、长期任务多步骤、深层导航、完整工作区无需离开当前上下文的轻任务
Popover依附触发点的短结果简短说明或最多两个操作详情、长内容与编辑表单

层级与滚动

禁止 Drawer 嵌套

二次确认改用轻量 Modal，避免多层侧滑。

只滚动 Content

Header 与 Footer 固定，不随长内容离开视口。

关闭与焦点

统一检查未保存状态

Close、Cancel、Esc 与蒙层关闭执行相同保护。

焦点进入、限制、返回

打开后进入抽屉，关闭后返回原触发元素。

动效与操作

260ms ease-out

从右侧进入并反向退出，不叠加弹跳。

最多一个 Primary

只读隐藏 Footer；表单保留取消和明确提交动作。
