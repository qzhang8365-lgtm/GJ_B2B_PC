头像 Avatar

用于在数字界面中直观表示特定用户或实体身份的可视化元素。

Avatar

头像

头像提供圆形与方形两种形状，以及默认图标、用户首字母和用户图片三种内容风格。

组件示例

基础用法

Size × Shape

头像有四种可选尺寸：64px、40px、32px、24px；两种形状：圆形和方形。

头像风格

Default / Letter / Picture

默认风格用于无用户资料时兜底；字母取用户名称首字母；图片使用真实头像资源。

带徽标的头像

Badge

通常用于消息提示。圆点表示存在新状态，数字徽标表示明确的未读数量。

12数量徽标状态圆点

头像组合

Avatar group

组合头像使用重叠排列；数量较多时仅展示代表头像，并在末尾使用“+数量”。

选用规则与边界

Usage rules
图片不可变形

图片填满头像容器并居中裁切，不允许拉伸。

缺失信息有兜底

优先图片，其次用户首字母，最后使用默认人物图标。

字母保持简洁

默认取一个可识别首字母，不在头像内承载完整姓名。

徽标不能遮挡主体

徽标放在右上角并保留容器色描边，确保与头像分离。

组合限制展示数量

头像过多时折叠为“+数量”，避免组合无限延伸。

同组规格统一

同一头像组保持相同尺寸、形状与重叠间距。
