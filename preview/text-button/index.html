文字按钮 Text Button

无背景、无描边、无可见内边距的轻量操作组件。标准灰色默认态与 Blue 可选变体并存，Blue 不替代标准契约。

颜色变体

默认优先使用标准灰色；只有业务明确需要更强可操作性提示时才声明 Blue。同一操作组保持一致。

选用规则

Text Button 负责轻量操作，不承担主提交或高风险确认。

主题推荐做法边界与避免
默认颜色绝大多数场景使用标准灰色变体。不得为了“像链接”而把所有 Text Button 默认改蓝。
Blue 变体业务明确要求操作入口持续可见时显式声明。同一张表或同一操作组不得混用两种默认色。
尺寸按容器层级选择 Large / Medium / Small；表格行内操作使用 Small。同一操作组不得混用尺寸。
图标使用组件库图标并通过 currentColor 跟随文字。不支持 Icon-only；纯图标操作改用 Icon Button。
点击热区需要扩大时由外层命中区域或伪元素提供。不得增加可见 padding 或改变 Text Button 行盒高度。
