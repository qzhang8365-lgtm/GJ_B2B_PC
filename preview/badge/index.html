徽标 Badge

一般出现在通知图标、头像或文字的右上角，用醒目的圆点或数字提示用户存在待处理信息。

Badge

徽标

徽标只承担提示和计数，不替代完整状态说明；重要数字应设置封顶值，避免徽标持续扩张。

选用规则与边界

Usage rules
有数量才显示

数量为 0 时隐藏数字徽标，不显示无意义的“0”。

设置合理封顶值

根据业务空间选择 99+ 或 999+，封顶值不应频繁变化。

圆点不表达数量

只需要提醒存在新内容时使用圆点；需要数量时改用数字徽标。

颜色表达语义

状态圆点使用对应语义变量，不使用临时色值或装饰性色彩。

避免重复提示

同一对象不要同时叠加圆点和数字徽标。

依附关系明确

徽标固定在对象右上角，不应漂浮到相邻元素范围。
