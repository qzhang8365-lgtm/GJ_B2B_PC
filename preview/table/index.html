选用规则与边界

Usage rules
主题推荐做法边界与避免
字段优先级优先展示名称、状态和关键数据；低优先级字段放入详情或折叠区域。不要通过无限压缩让主要内容不可读。
列宽策略短字段固定宽度，主文本列弹性伸缩；长文本省略并提供完整查看方式。不要让浏览器宽度变化破坏列的基本可读宽度。
批量选择显示已选数量，明确当前页/跨页全选范围，并提供清除选择入口。不要让全选范围或批量操作对象含糊。
排序与筛选显示当前方向和已生效条件，并支持恢复默认状态。不要同时呈现互相冲突的排序或筛选状态。
结构分割使用 Table 语义分割线；最后一行由容器收口，不重复添加底线。不要用一级卡片描边代替表格内部结构线。
横向溢出列数超出时在表格容器内横向滚动；必要时固定末列操作并用阴影提示层级。示例和业务表格均不得溢出页面容器或遮挡相邻区域。
