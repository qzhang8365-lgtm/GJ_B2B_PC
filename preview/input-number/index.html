Usage rules
主题推荐做法边界与避免
数值边界必须定义最小值、最大值、步长与精度，越界时及时反馈。静默截断、自动改值却不告知用户。
单位金额、比例等固定单位与数值绑定展示。要求用户在输入值中重复键入单位。
适用数据用于数量、比例、金额等可计算数值。账号、证件号等数字字符串使用 InputNumber。
禁用与错误说明不可操作或校验失败原因，并保留合法旧值。只降低透明度，或错误后清空用户输入。
