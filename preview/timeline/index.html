信息展示组件 · Data Display

时间轴 Timeline

用于按时间顺序呈现事件、进度记录或阶段历史，帮助用户理解事件发生的先后关系和当前状态。

主要类型

纵向适合阅读事件详情与历史记录；横向适合展示数量有限、阶段清晰的时间进程。节点样式在同一组内应保持一致。

方向：纵向
方向：横向
节点样式：Dot / Checkmark

状态

Finished 节点必须连续，Waiting 不得夹在已完成节点之间；Checkmark 只表示完成，不表示当前或异常。

交互演示

切换方向、节点样式与节点数量；横向可通过左右箭头翻页。演示中点击节点仅用于调整「已完成至」，业务时默认不可点击。

属性控制

最近事件：尚未操作

结构与规格

按组成部分拆开阅读；纵向、横向共用节点与状态语义，尺寸和文字样式均由组件 Token 驱动。

基本组成

Node + Connector + Content

节点表达状态，连接线串联顺序，内容区承载时间、标题与说明。

纵向节点

容器 20×20 · Dot 10×10

Dot 使用圆形节点；Finished 为品牌蓝，Waiting 为禁用色。

Checkmark

16×16px

引用 icf_system_check-circle-fill，仅表示节点已完成。

连接线

1px dashed · Border/hover

Waiting 只改变节点颜色，纵向连接线样式保持不变。

纵向文字

标题 14/22 · 说明 12/18

标题使用中文/S5-CN-S；说明使用中文/S9-CN-R，建议控制在 1–3 行。

横向单元

155×112px 基准

标题、说明均为 14/22；空间不足时翻页，不压缩单元宽度。

选用规则

Timeline 用于呈现已经发生或按计划将要发生的事件，不承担流程进度提交的职责。

主题推荐做法边界与避免
方向选择详情多或节点多时使用纵向；数量有限、阶段清晰时可用横向。避免为了横向排布而压缩文字和单元宽度。
时间与排序默认按真实时间正序，同一条时间轴保持日期粒度和格式一致。倒序必须明确标注，不混用日期、月份与时分秒。
状态连续性Finished 节点必须连续，Waiting 只能出现在其后。Checkmark 只表示完成，不表示当前、异常或警告。
内容长度标题允许换行，详情建议 1–3 行；更多内容通过展开或详情入口承载。不要让长文案无限撑高节点或破坏组内节奏。
交互边界默认作为信息展示；仅在允许查看详情时让标题或整项可点击。演示中的步骤按钮用于理解状态，不代表业务组件必须可编辑。
空与加载没有事件时使用 Empty；异步加载时保留稳定容器。避免数据返回前后出现明显布局跳动。
