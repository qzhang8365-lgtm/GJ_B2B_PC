时间轴 Timeline

用于按时间顺序呈现事件、进度记录或阶段历史，帮助用户理解事件发生的先后关系和当前状态。

组成结构

节点表达事件是否已完成，连接线串联相邻事件的先后关系，内容区承载标题与说明。

Item时间轴事件
=
Node节点，Dot 或 Checkmark，表达 Finished / Waiting
+
Connector连接线，串联相邻事件
+
Content标题与说明

主要类型

纵向适合阅读事件详情与历史记录；横向适合展示数量有限、阶段清晰的时间进程。节点样式在同一组内应保持一致。

方向：纵向
方向：横向
节点样式：Dot / Checkmark

状态

Finished 节点必须连续，Waiting 不得夹在已完成节点之间；Checkmark 只表示完成，不表示当前或异常。

交互演示

切换方向、节点样式与节点数量；横向可通过左右箭头翻页，点击任意节点可将其设为当前节点。

属性控制

最近事件：尚未操作

结构与规格

纵向、横向共用同一套节点与状态语义，尺寸和文字样式均由组件 Token 驱动。

选用规则

Timeline 用于呈现已经发生或按计划将要发生的事件，不承担流程进度提交的职责。

主题推荐做法边界与避免
时间排序默认按真实时间正序展示。如采用倒序应明确标注并保持整个页面一致。
方向选择详情多、节点多时使用纵向。横向仅用于数量有限且阶段清晰的进程。
节点状态完成节点必须连续。等待状态不得夹在已完成节点之间。
长内容标题可换行，详情建议 1–3 行。更多内容通过展开或详情入口承载，不撑破单元。
横向溢出保持 155px 基准单元宽，提供左右切换。容器不足时不得挤压文字或压缩单元宽度。
时间格式同一条时间轴使用相同日期粒度和格式。不混用日期、月份与时分秒。
Checkmark 语义只用于表示节点已完成。不得用作当前进行中或异常状态。
交互边界默认用于信息展示。仅在允许查看详情时让标题或整项可点击。
无数据与加载没有事件时使用 Empty 组件。异步加载时保留稳定容器，不使布局跳动。
