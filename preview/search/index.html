搜索框 Search

搜索帮助用户从大量信息中快速缩小目标范围。结果可实时计算时使用即时联想列表；查询成本较高或条件复杂时改用搜索按钮，由用户确认后触发。Small/Medium/Large 高度 24/32/40px，圆角 4/6/8px，参考宽度 233px，可按业务容器调整，不因响应式布局任意拉伸变形。

组成结构

搜索框本身只负责关键词输入与状态展示；确认按钮与结果列表按使用模式挂载。

搜索框 Search承载关键词与展示状态
图标 Icon提示搜索意图，默认弱化显示
输入区 Input记录关键词，反映聚焦与填写状态
清除按钮 Clear有输入时出现，一键清空

使用模式

两种模式共用同一套搜索框基座，差异只在触发方式与结果呈现。

确认搜索Search + Button

输入后点击按钮或按 Enter 触发查询，适合查询成本较高或条件复杂的场景。按钮尺寸需与搜索框档位一致，间距固定 8px。

即时联想Instant Suggest

输入过程中实时展示候选结果，命中词使用 Text/blue 高亮，适合结果可快速计算的场景。

尺寸与状态

结构与选用规则

确认与联想两种模式共用同一套尺寸、状态与键盘行为规范。

主题推荐做法边界与避免
模式选择结果可实时计算时用即时联想；查询成本高或条件复杂时用确认按钮。不要让用户靠猜测判断当前需要点击按钮还是等待联想结果。
结果列表宽度始终跟随搜索框，命中词使用 Text/blue 高亮；结果项高 32px。不要让结果列表脱离输入框独立变宽、变窄或错位。
空结果无匹配结果时展示明确的 Empty 提示。不要保留上一次查询的旧结果，造成结果仍在更新的误导。
清空与键盘有输入时展示清除按钮；支持 ↑/↓ 切换结果、Enter 选择、Esc 关闭。清空后不应残留候选列表、高亮或选中态。
与筛选的边界复杂多条件查询组合 Form、Selector 等已有基座，并提供清除条件入口。不要把搜索框当成承载全部筛选条件的万能控件。
宽度参考宽度 233px，可按业务容器调整；与按钮组合间距固定 8px，按钮尺寸须与搜索框一致。不要因响应式布局把搜索框任意拉伸变形。
