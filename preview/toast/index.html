轻提示 Toast

用于反馈操作结果、系统状态或轻量提醒。Toast 不阻断当前任务，可自动消失，也可按需要提供关闭入口。

Toast

短暂 · 非阻断 · 结果明确 · 无需立即决策

Toast 应在操作后即时出现，使用一句明确文案说明对象与结果。需要用户决策、长期保留或承载多项操作时，应改用 Modal、Notification 或 Popover。

外观类型

Float / Transparent / Black

Float 浮层型

保存成功

白色容器配合 shadow-center，适用于保存、提交、复制等全局操作结果。

Transparent 语义背景型

请检查未填写的内容

以轻量语义色强化状态，适合连续流程中的快速区分。

Black 黑底型

已复制

更紧凑，适合浏览、预览、复制成功等即时提示；视口叠加默认底部居中。

行为与选用规则

Usage rules
显示位置

Float、Transparent 出现在页面顶部居中；Black 出现在页面底部居中。距边缘均为 24px。

显示时长

成功 2–3 秒；信息 3 秒；警告与失败 4–5 秒；加载状态不自动消失。

关闭入口

短成功提示可隐藏关闭按钮；较长信息、警告与失败提示应保留关闭入口。

加载状态原位更新

加载结束后在同一位置替换为成功或失败，不应再次叠加一条结果 Toast。

文案直接说明对象与结果

推荐“保存成功”“报告导出中，请稍候”“未能删除策略，请重试”，避免只写“系统提示”或“操作失败”。

边界

确认决策使用 Modal；持久通知或多操作使用 Notification；表单校验使用字段内联错误。

无障碍要求

Accessibility
播报优先级

Info、Success、Loading 使用 role=status 与 aria-live=polite；紧急 Error 才使用 role=alert。

不只依赖颜色

始终保留状态图标与明确文案；关闭按钮提供 aria-label=关闭提示。

暂停与动效

鼠标悬停或键盘聚焦时暂停计时，并支持 prefers-reduced-motion。

交互属性

Float/Transparent 顶部，Black 底部
最多同时展示 3 条；悬停可暂停关闭计时
