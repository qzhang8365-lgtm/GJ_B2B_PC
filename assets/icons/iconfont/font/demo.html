GJ B端 Iconfont 使用示例

Fill 风格

<i class="gj-fill gj-fill-icf-system-bell-fill"></i>

<i class="gj-fill gj-fill-icf-system-search-fill"></i>

<i class="gj-fill gj-fill-icf-file-file-fill"></i>

Line 风格

<i class="gj-line gj-line-icf-system-bell"></i>

<i class="gj-line gj-line-icf-system-search"></i>

<i class="gj-line gj-line-icf-file-file-line"></i>

使用方法

1. 引入 CSS:
   <link rel="stylesheet" href="gj-icon-fill.css">  <!-- 只需 fill -->
   <link rel="stylesheet" href="gj-icon-line.css">  <!-- 只需 line -->

2. 使用图标:
   <i class="gj-fill gj-fill-icf-system-bell-fill"></i>
   <i class="gj-line gj-line-icf-system-bell"></i>

3. 控制大小和颜色 (CSS):
   i { font-size: 24px; color: #2b73ff; }
