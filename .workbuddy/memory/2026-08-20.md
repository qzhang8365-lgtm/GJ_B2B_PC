## Sidebar 组件页：四项修复（嵌套 button 提权 / 基础用法精简 / props 区压缩 / 深底）

### 1. 嵌套 `<button>` 提权 bug（用户："箭头单独成行没在 item 里"）
- **根因**：HTML5 规范禁止 `<button>` 嵌套 `<button>`。原代码 `firstItemMarkup/secondItemMarkup` 把 `<button class="arrow-button">` 嵌进了 `<button class="nav-item/sub-item">`，浏览器解析时**自动把内层 button 提到外层 button 之外**，导致箭头被挪到 nav-item 后面、视觉上"单独成行"。
- **DevTools 实测证据**：
  ```
  arrow-button.parent_tag    = NAV (sidebar-menu)        ← 实际在外层
  arrow-button.parent_class  = sidebar-menu              ← 不该是 menu
  ```
- **修复**：`arrowButton()` 把外层 `<button>` 改成 `<span role="button" tabindex="-1">`（用 role+tabindex 保留语义和事件委托可访问性）。事件委托 `closest('[data-toggle-level]')` 不依赖元素类型，零 JS 改动。修复后实测 `arrow_in_navitem=true` / `arrow_in_subitem=true`，箭头正确回到 item 内部。

### 2. 基础用法精简（用户："三种颜色不要全部展示，默认展开 + 加切换按钮"）
- 原：3 种 mode（light/dark/background）× 展开/收起 = 6 个 sidebar 实例
- 改：只展示 1 个 sidebar（背景色推荐方案），默认 `expanded`，右上角"收起侧边栏"按钮切换 `ui.basicCollapsed` 状态
- CSS：`.variant-row` 由 `repeat(3, 1fr)` 改 `1fr` 单列；新增 `.basic-toolbar` / `.basic-toggle` 按钮样式（白底 32px 高，hover/active 用蓝色高亮 + 浅蓝底）
- JS：`ui` 初始化加 `basicCollapsed:false`；`renderBasic` 重写为单 sidebar + 切换按钮 + 切换后自动重渲染
- 验证：DevTools 点击 1 次 → className `mode-background collapsed` / btn "展开侧边栏" / width=56；再点 1 次 → `expanded` / btn "收起侧边栏" / width=200

### 3. props 区压缩宽度（用户："压缩代码演示区域宽度和其它页面保持一致"）
- 原：`.props` 无 max-width，被 grid 2fr 列撑到 ~558px，内容稀疏显空荡
- 改：`.props{max-width:380px}` 限制最大宽度（与 gridnav 的 `tabs-card` 思路一致：宽度按内容自适应）
- 验证：实测 props 渲染 width=380px / maxWidth="380px"

### 4. props 区背景色与 button 页一致（用户："代码区背景颜色和其它页面保持一致"）
- 原：`.props{background:transparent;color:var(--secondary);...}` 浅字透明底
- 参考 `preview/button/index.html` L30：`.props{background:#101828;color:#d0d5dd;padding:14px;border-radius:8px;font:13px/1.65 ui-monospace,...}` 深底浅字
- 改：`.props{background:#101828;color:#d0d5dd;padding:14px;border-radius:8px;border-top:0;max-width:380px;font:12px/1.65 var(--mono);white-space:pre-wrap;overflow:auto}`
- 验证：实测 `backgroundColor=rgb(16,24,40)` / `color=rgb(208,213,221)`，与 button 页一致

### 教训
- **HTML 嵌套规则**：button 不能嵌套 button / textarea / select 等 interactive 元素。遇到"按钮里塞另一个按钮"的需求，要么改 span+ARIA，要么把外层改成 div+role="button"。事件委托（closest + data-attr）能无感知兼容。
- **跨页面样式对齐**：本次 props 背景色问题说明组件页之间需要共享 `<pre class="props">` 样式 token（比如统一用 `--code-bg` / `--code-fg` CSS 变量），未来建 `preview/_shared.css` 或 design token 时一并抽出来。
