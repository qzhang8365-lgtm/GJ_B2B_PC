## 图标预览页（preview/icons/index.html）弹窗按钮布局修复
- 问题：弹窗底部三个按钮（复制 SVG / 下载 SVG / 下载 PNG）竖排。
- **真正的根因（不是缓存！）**：本地 `preview/icons/index.html` 的 CSS 中，`.modal-actions` 选择器前被插入了 4 个多余的点（`....modal-actions`），导致选择器非法、整条规则被浏览器静默丢弃，按钮退回默认竖排。grep 只匹配到 `.modal-actions{...}` 子串，所以表面看着"正确"，浏览器解析却失败。

- 排查教训：CSS 选择器前出现非预期字符（如 `....`）会让整条规则静默失效，且 grep 子串匹配无法察觉。定位要靠逐字节 diff + 看浏览器实际计算样式。

## 侧边导航三级菜单默认收起（preview/index.html 外层导航栏）
- 需求：侧边导航栏**三级默认收起**，默认只展示到二级（一级 section 默认展开、二级可见）。这是全局导航栏问题（不是某个 iframe 子页），与上一轮背景修复同理——导航栏在外层 index.html，所有页面共用。
- 根因：二级 `.nav-children` 有展开/收起逻辑（`.nav-section.collapsed .nav-children{display:none}` 默认展开）；但三级 `.nav-subchildren` 只有 margin/padding/border，**无 display 控制**，div 默认 block → 永远展开。
- 修复：
  1. CSS：`.nav-subchildren` 加 `display:none`（默认收起）；新增 `.nav-entry.expanded>.nav-subchildren{display:block}`（展开态显示）；`.nav-entry.has-sub.expanded>.nav-item .chevron{transform:rotate(0)}`（chevron 旋转）。
  2. JS `itemMarkup`：有 children 的二级 entry 加 `has-sub` class，并在按钮末尾加 chevron（⌄）。
  3. JS click handler：点击 `has-sub` 的二级 item 时 `toggle('expanded')` 同时 openPage。
  4. JS `openPage`：通过 hash 直开三级页面时，自动给父级二级 entry 加 `expanded`，使其可见可高亮。
- 验证（按铁律，非 grep 子串）：CSS 规则解析确认 `.nav-subchildren{...display:none}` + 展开规则存在；JS 用 `node --check` 语法通过；服务器 HTTP 200 且返回新 CSS/JS。交互效果需在浏览器实际确认（默认三级收起，点二级可展开）。
