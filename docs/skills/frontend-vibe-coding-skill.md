# GJ_B2B建设 Frontend Vibe Coding Skill

## 目标
帮助前端开发在使用组件库时，保持“企业级、可靠、清晰、可扩展”的实现风格。

## 使用步骤
1. 先确认业务角色：业主、总包、供应商、平台运营或财务。
2. 优先复用组件库已有模式：按钮、表单、数据表、状态标签、空状态、详情抽屉。
3. 任何新增组件都必须同时补齐：视觉展示、交互说明、代码片段、使用建议、禁用场景。
4. 所有样式优先引用 design token，不直接散落临时颜色、圆角和阴影值。
5. B 端页面默认支持键盘可达、清晰焦点态、表单错误提示和低对比度禁用态。

## 输出格式
- 组件名称：使用 PascalCase。
- Props：列出类型、默认值、必填项和边界行为。
- 示例：至少提供基础示例、业务示例、禁用/错误态示例。
- 规范：说明适合场景、不适合场景、内容文案建议。

## 代码风格
- HTML 结构先保证语义化，再叠加视觉样式。
- CSS 使用 token 变量，例如 `var(--color-primary)`、`var(--radius-md)`。
- 交互状态必须覆盖 hover、focus-visible、disabled、loading。
- 数据密集型组件需要明确空态、加载态、错误态和批量操作反馈。
