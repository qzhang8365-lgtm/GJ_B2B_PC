发布包沿用精简结构：SKILL.md、references、assets、scripts及根目录说明/依赖清单；不含预览站、Git历史、node_modules、过程截图、导出备份和测试页。人工规范站单独发布。

已完成Token、覆盖状态、脚本语法、内嵌资源及业务组件浏览器验收。资讯Hover圆角和视频独立滑块审计已关闭；视频时间文字的Figma颜色绑定与Tag规范页角标迁移仍按审计台账跟踪，不影响本版已实现的交互。
